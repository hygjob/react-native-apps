# 📖 코드 설명서 - 초심자를 위한 가이드

이 문서는 애완견 알림장 서비스의 코드를 초심자가 이해할 수 있도록 상세히 설명합니다.

---

## 📁 프로젝트 구조 개요

이 프로젝트는 **백엔드(Backend)**와 **프론트엔드(Frontend)**로 나뉩니다.

- **백엔드**: 서버 역할. 데이터를 저장하고 API를 제공합니다.
- **프론트엔드**: 모바일 앱. 사용자가 보는 화면과 기능을 제공합니다.

## 🔧 Backend (백엔드)

백엔드는 **Node.js**와 **Express** 프레임워크를 사용하여 웹 서버를 만듭니다.

```json
{

    "express": "^4.18.2",    // 웹 서버 프레임워크

    "sqlite3": "^5.1.6",     // 데이터베이스
```

**설명**: 이 파일은 프로젝트가 사용하는 라이브러리들을 정의합니다. `npm install`을 실행하면 이 라이브러리들이 자동으로 설치됩니다.

### 📄 `database.js` - 데이터베이스 관리

이 파일은 **SQLite** 데이터베이스를 설정하고 관리합니다.

#### 주요 개념

1. **SQLite**: 파일 기반 데이터베이스. 별도의 서버 설치 없이 사용 가능합니다.
2. **테이블**: 데이터를 저장하는 표 형태의 구조입니다.
3. **SQL 쿼리**: 데이터베이스에 명령을 내리는 언어입니다.

#### 코드 구조

```javascript
// 1. 데이터베이스 연결
const db = new sqlite3.Database(dbPath);

// 2. 테이블 생성 (알림장 저장용)
CREATE TABLE notices (
  id INTEGER PRIMARY KEY AUTOINCREMENT,  // 자동 증가하는 고유 번호
  title TEXT NOT NULL,                   // 제목 (필수)
  content TEXT NOT NULL,                 // 내용 (필수)
  image_url TEXT,                        // 이미지 경로 (선택)
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP  // 생성 시간
)

// 3. 함수들
- createNotice(): 알림장 생성 (INSERT)
- getAllNotices(): 모든 알림장 조회 (SELECT)
- getNoticeById(): 특정 알림장 조회 (SELECT)
```

#### 왜 이렇게 작성했나요?

- **플레이스홀더(`?`) 사용**: SQL 인젝션 공격을 방지하기 위해 `?`를 사용합니다.
- **콜백 함수**: SQLite는 비동기 작업이므로, 작업이 끝나면 콜백 함수를 호출합니다.

### 📄 `server.js` - Express 서버

이 파일은 웹 서버를 만들고 API 엔드포인트를 정의합니다.

#### 주요 개념

1. **Express**: Node.js용 웹 프레임워크. HTTP 요청을 쉽게 처리할 수 있습니다.
2. **미들웨어**: 요청과 응답 사이에서 실행되는 함수입니다.
3. **API 엔드포인트**: 클라이언트가 서버에 요청할 수 있는 주소입니다.

#### 코드 흐름

```
1. Express 앱 생성
   ↓
2. 미들웨어 설정
   - CORS: 다른 도메인에서 접근 허용
   - JSON 파싱: JSON 형식 데이터 처리
   - 파일 업로드: Multer 설정
   ↓
3. API 엔드포인트 정의
   - POST /api/notices: 알림장 생성
   - GET /api/notices: 모든 알림장 조회
   - GET /api/notices/:id: 특정 알림장 조회
   ↓
4. 서버 시작 (포트 3000)
```

#### 주요 코드 설명

**1. 파일 업로드 설정 (Multer)**
```javascript
const storage = multer.diskStorage({
  destination: 'uploads/',  // 파일 저장 위치
  filename: (req, file, cb) => {
    // 중복 방지를 위해 타임스탬프 + 랜덤 숫자로 파일명 생성
    cb(null, 'image-' + Date.now() + '-' + Math.random() + '.jpg');
  }
});
```

**2. 알림장 생성 API**
```javascript
app.post('/api/notices', upload.single('image'), (req, res) => {
  // req.body: 텍스트 데이터 (title, content)
  // req.file: 업로드된 파일 정보
  const { title, content } = req.body;
  const imageUrl = req.file ? `/uploads/${req.file.filename}` : null;
  
  // 데이터베이스에 저장
  createNotice(title, content, imageUrl, (err, notice) => {
    if (err) {
      res.status(500).json({ error: '실패' });
    } else {
      res.json({ success: true, notice });
    }
  });
});
```

**3. 정적 파일 제공**
```javascript
app.use('/uploads', express.static(uploadDir));
```
이 코드는 `/uploads/image-123.jpg` 같은 URL로 이미지 파일에 접근할 수 있게 합니다.

### 📄 `store/noticeStore.js` - 전역 상태 관리 (Zustand)

이 파일은 **Zustand**를 사용하여 앱 전체에서 공유되는 상태를 관리합니다.

#### 주요 개념

1. **상태 관리**: 여러 화면에서 같은 데이터를 공유할 때 사용합니다.
2. **Zustand**: Redux보다 간단한 상태 관리 라이브러리입니다.
3. **Store**: 상태와 함수를 저장하는 저장소입니다.

#### 코드 구조

```javascript
const useNoticeStore = create((set, get) => ({
  // 상태 (State)
  notices: [],      // 알림장 목록
  loading: false,   // 로딩 중 여부
  error: null,      // 에러 메시지

  // 액션 (Actions)
  fetchNotices: async () => {
    // 1. 로딩 시작
    set({ loading: true });
    
    // 2. API 호출
    const response = await fetch(`${API_URL}/notices`);
    const data = await response.json();
    
    // 3. 상태 업데이트
    set({ notices: data.notices, loading: false });
  },
  
  createNotice: async (title, content, imageUri) => {
    // FormData 생성 (파일 업로드용)
    const formData = new FormData();
    formData.append('title', title);
    formData.append('content', content);
    formData.append('image', { uri: imageUri, ... });
    
    // API 호출
    const response = await fetch(`${API_URL}/notices`, {
      method: 'POST',
      body: formData
    });
  }
}));
```

#### 왜 Zustand를 사용하나요?

- **간단함**: Redux보다 코드가 훨씬 간단합니다.
- **TypeScript 지원**: 타입 안정성을 제공합니다.
- **성능**: 필요한 부분만 리렌더링합니다.

#### FormData란?

파일을 업로드할 때 사용하는 형식입니다. 텍스트와 파일을 함께 전송할 수 있습니다.

```javascript
const formData = new FormData();
formData.append('title', '제목');
formData.append('image', { uri: 'file://...', name: 'photo.jpg', type: 'image/jpeg' });
```

```javascript
const pickImage = async () => {
  // 1. 권한 요청
  const { status } = await ImagePicker.requestMediaLibraryPermissionsAsync();
  
  // 2. 갤러리 열기
  const result = await ImagePicker.launchImageLibraryAsync({
```

```javascript
const handleSubmit = async () => {
```

### 📄 `app/customer.js` - 고객 화면

#### 주요 개념

```
   ↓

   ↓
4. 알림장 목록 표시 (FlatList)
   ↓

```

#### 주요 코드 설명

**1. 컴포넌트 마운트 시 데이터 가져오기**
```javascript
useEffect(() => {
  fetchNotices();  // 알림장 목록 가져오기
}, []);  // 빈 배열: 처음 한 번만 실행
```

**2. 에러 처리**
```javascript
useEffect(() => {
  if (error) {
    Alert.alert('오류 발생', error);
  }
}, [error]);  // error가 변경될 때마다 실행
```

**3. FlatList로 목록 렌더링**
```javascript
<FlatList
  data={notices}                    // 표시할 데이터

      refreshing={loading}
      onRefresh={fetchNotices}       // 새로고침 함수
    />
  }
/>
```

**4. 각 알림장 항목 렌더링**
```javascript
const renderNoticeItem = ({ item }) => (
```

### 📄 `app/notice-detail.js` - 알림장 상세 화면

1. **useLocalSearchParams**: URL 파라미터를 가져오는 Hook입니다.
2. **동적 라우팅**: URL에 따라 다른 데이터를 표시합니다.

#### 코드 구조

```javascript
export default function NoticeDetailScreen() {
  const { id } = useLocalSearchParams();  // URL에서 id 가져오기
  const [notice, setNotice] = useState(null);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    // 알림장 상세 정보 가져오기
    fetch(`${API_URL}/notices/${id}`)
      .then(res => res.json())
      .then(data => setNotice(data.notice));
  }, [id]);

  return (
    <ScrollView>
      <Image source={{ uri: notice.image_url }} />
      <Text>{notice.title}</Text>
      <Text>{notice.content}</Text>
    </ScrollView>
  );
}
```

## 🔄 전체 데이터 흐름

### 알림장 생성 흐름

```
1. 선생님 화면 (teacher.js)
   ↓ 사용자가 제목, 내용, 이미지 입력
   ↓ "등록하기" 버튼 클릭
   
2. Zustand Store (noticeStore.js)
   ↓ createNotice() 함수 호출
   ↓ FormData 생성
   
3. 백엔드 API (server.js)
   ↓ POST /api/notices 요청 수신
   ↓ Multer로 이미지 저장
   ↓ database.js의 createNotice() 호출
   
4. 데이터베이스 (database.js)
   ↓ SQLite에 데이터 저장
   ↓ 생성된 알림장 반환
   
5. 응답
   ↓ 성공 응답 반환
   ↓ Zustand store에 새 알림장 추가
   ↓ 고객 화면으로 이동
```

### 알림장 조회 흐름

```
1. 고객 화면 (customer.js)
   ↓ 화면 표시 시 useEffect 실행
   ↓ fetchNotices() 호출
   
2. Zustand Store (noticeStore.js)
   ↓ GET /api/notices 요청
   
3. 백엔드 API (server.js)
   ↓ GET /api/notices 요청 수신
   ↓ database.js의 getAllNotices() 호출
   
4. 데이터베이스 (database.js)
   ↓ SQLite에서 모든 알림장 조회
   ↓ 최신순으로 정렬하여 반환
   
5. 응답
   ↓ 알림장 목록 반환
   ↓ Zustand store에 저장
   ↓ FlatList로 화면에 표시
```

## 🎓 초심자를 위한 핵심 개념 정리

### 1. React Native 기본 컴포넌트

- **View**: `<div>`와 유사. 컨테이너 역할
- **Text**: 텍스트를 표시
- **TouchableOpacity**: 터치 가능한 버튼
- **TextInput**: 입력 필드
- **Image**: 이미지 표시
- **FlatList**: 리스트 렌더링 (성능 최적화)
- **ScrollView**: 스크롤 가능한 뷰

### 2. React Hooks

- **useState**: 컴포넌트 내부 상태 관리
  ```javascript
  const [value, setValue] = useState(초기값);
  ```

- **useEffect**: 부수 효과 (API 호출, 구독 등)
  ```javascript
  useEffect(() => {
    // 실행할 코드
  }, [의존성 배열]);  // 의존성이 변경될 때마다 실행
  ```

### 3. 비동기 처리 (Async/Await)

```javascript
// Promise를 사용한 비동기 처리
const fetchData = async () => {
  try {
    const response = await fetch('http://...');
    const data = await response.json();
    console.log(data);
  } catch (error) {
    console.error('에러:', error);
  }
};
```

### 4. API 통신 (Fetch API)

```javascript
// GET 요청
const response = await fetch('http://localhost:3000/api/notices');
const data = await response.json();

// POST 요청
const response = await fetch('http://localhost:3000/api/notices', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ title: '제목', content: '내용' })
});
```

### 5. 파일 업로드 (FormData)

```javascript
const formData = new FormData();
formData.append('title', '제목');
formData.append('image', {
  uri: 'file:///path/to/image.jpg',
  name: 'image.jpg',
  type: 'image/jpeg'
});

const response = await fetch('http://localhost:3000/api/notices', {
  method: 'POST',
  body: formData  // Content-Type은 자동 설정됨
});
```

## ⚠️ 주의사항

### 1. IP 주소 설정

모바일 기기나 에뮬레이터에서 테스트할 때는 `localhost` 대신 실제 IP 주소를 사용해야 합니다.

```javascript
// ❌ 잘못된 예 (모바일에서 작동 안 함)
const API_URL = 'http://localhost:3000/api';

// ✅ 올바른 예
const API_URL = 'http://192.168.219.101:3000/api';
```

### 2. CORS 설정

백엔드에서 `cors()` 미들웨어를 사용하여 다른 도메인에서의 요청을 허용해야 합니다.

### 3. 파일 경로

React Native에서는 이미지 URI를 사용할 때 `file://` 프로토콜을 사용합니다.

```javascript
// 로컬 파일
source={{ uri: 'file:///path/to/image.jpg' }}

// 네트워크 이미지
source={{ uri: 'http://192.168.219.101:3000/uploads/image.jpg' }}
```
